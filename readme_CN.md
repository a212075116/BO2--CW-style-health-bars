--------------------------------------------------------------------------------
一、工作原理（数据流）
--------------------------------------------------------------------------------
  GSC 每 0.1s 遍历丧尸/地狱犬，把数据打包到多个“客户端 dvar”（分批，避免单
  个 dvar 太长被截断）：
      zh_data_0 .. zh_data_N   "entNum:ratio100:alpha100:name;..."
  LUI 每 0.1s 轮询这些 dvar，按实体号 key 出每只的血条，用 setupEntityContainer
  跟随实体。

  伤害数字走独立事件通道：
      zh_dmg                    "entNum:amount:seq:distance;..."
  LUI 读取后，每个命中占用数字池一个槽位，锚定到 GSC 在命中点生成的静态锚点，
  竖直上飘。

  为何不用 luinotifyevent / client field/server dvar：本作这些通道不可用或预算
  耗尽；客户端 dvar + UIExpression.DvarString 是实测能到达 LUI 的唯一可靠通道。

  PS：如果有更好的办法，期望有人可以改进

--------------------------------------------------------------------------------
二、可调参数
--------------------------------------------------------------------------------
  [A] LUI —— ui_mp\t6\zombie\zombiehealthbars.lua 顶部常量：
      BARW / BARH         血条宽高（60 / 6）
      HEADZ               血条相对头顶的偏移（70）
      ICONW / ICONGAP     左侧图标尺寸 / 与血条间距（12 / 6）
      MaxDmg              伤害数字池大小（16）
      DMGSTEPS            上飘帧数（17，约 0.85s；越大越慢）
      DMGRISE             总上升像素（30）
      DMGTOP              远距离起点相对血条的偏移（6）
      DMGBODY             近距离（贴脸）起点高度——丧尸身体（30）
      DMGDISTREF          达到“远距离起点”所需的距离（200）
      DMGSLOW             近距离额外滞空帧数（越近越慢）（18）
      NUMDVARS            分批 dvar 数量（8）

  [B] GSC —— scripts\zh_healthbars.gsc：
      显示距离          近距显示阈值 260；满亮距离 100；准星显示上限 900
      准星判定          dot > 0.99
      死亡衰减窗口       600ms
      分批大小          zh_batch = 10（每批丧尸数）；zh_dvars = 8（dvar 数）



--------------------------------------------------------------------------------
三、安装
--------------------------------------------------------------------------------

分两种安装方法：
第一种：直接在一个已有的mod上安装即可。
  %localappdata%\Plutonium\storage\t6\mods\<The folder you want to install on the mod>

第二种：直接安装在 %localappdata%\Plutonium\storage\t6 下
